🗺️ PawMap — analytique

        

          Vue d'ensemble des POIs (vétos, parcs, points d'eau...) et des signalements communautaires (chien perdu, danger, point d'eau, etc.).
          Tous les signalements sont conservés — même après expiration 48 h — comme dataset historique. Utile pour repérer les hotspots et détecter les abus.
        


        
        

          
🌱 Alimenter la carte (OpenStreetMap)

          

            Charge automatiquement les POIs depuis OpenStreetMap pour un pays européen, un état américain, une province canadienne — ou toute l'Europe, tous les USA, tout le Canada.
            Les catégories couvrent vétos, parcs à chiens, boutiques, toiletteurs, points d'eau, hôtels/restos pet-friendly.
            Le seed tourne en tâche de fond (1-3 min par pays/état). « Tout l'Europe + Suisse » = 29 pays d'un coup ; « Tous les USA » = 50 états + DC.
